# 微信小程序使用手册

本手册对应 **Life 微信小程序版**。小程序与 [Web 版](../quick-start)功能略有不同：
小程序主打随手记与查看，完整功能（含统计图表、聊天模式）在 Web 端。

## 快速开始

<StepBox title="1. 打开即用">
微信中搜索「Life 记账健康助手」或扫码打开，自动登录。无需注册步骤，打开就能记。
</StepBox>

<StepBox title="2. 绑定手机号（推荐）">
首页顶部横幅点「去绑定」，或「我的」页点「去绑定，查看历史数据」。
输入手机号 → 获取验证码 → 确认绑定。绑定后可在任何设备查看同一手机号账号下的全部历史数据，
当前微信里的记录会并入该账号。
</StepBox>

<InfoBox variant="warning" title="绑定不可逆">

绑定后微信将与该手机号账号长期关联，无法解绑换号。微信丢失或弃用时，可用原手机号验证码在新微信上接管账号、恢复全部数据（见文末常见问题）。不绑定也可以独立使用，只是换设备看不到历史数据。

</InfoBox>

## 使用指南

### 一句话记账

在首页输入框直接说，像发消息一样：

| 想做什么 | 可以这样说 |
|---|---|
| 记一笔支出 | 花了20吃午餐 |
| 查一笔账 | 这个月花了多少 |
| 改 / 删 | 删掉昨天的咖啡 |
| 记情绪 | 今天有点累 |
| 记服药 | 今天早上吃了药 |
| 记借贷 | 借出100 |

**所有写入操作都有确认卡，放心说：**

- **记好了**：显示「已记 N 笔」，可点**撤销**，或点**改类目**直接更正
- **修改 / 删除**：列出找到的记录，逐条点「确认修改 / 确认删除」才生效
- **没找到**：在卡片下方补充说明，如输入「是昨天那笔」，帮你重新定位
- **没识别**：换个更具体的说法（带上时间、金额、对象）再试

### 拍照批量记录

<StepBox title="拍照记录三步">
1. 点输入框左侧相机图标，拍照或从相册选择
2. 小程序读出图中文字（点「识别文字」可查看原文），列出可录入的条目
3. 逐条勾选，点「确认录入」一次性写入
</StepBox>

建议票面清晰、一次拍一张。非记账、健康类图片会提示无法识别，改用一句话记录即可。

{/* 截图位 3：识别候选卡（逐条勾选） */}

### 看板与明细

首页看板显示**今日支出 / 本月支出 / 待办完成率 / 最近记录**（多币种分开显示），点卡片进入明细。
明细页共 8 类：收支、情绪、待办、服药、测评、借贷、转账、余额调整；
其中前 5 类可按 **本月 / 近3月 / 近6月 / 全部** 筛选。

### 情绪与压力自评

1. 首页「情绪与压力」卡片进入
2. 选择一份自评：**情绪自评 / 压力自评 / 情绪速测**
3. 一屏一题，按「过去两周内」真实情况作答（完全不会 / 好几天 / 一半以上 / 几乎每天）
4. 提交后即时出结果，如「状态平稳」「略有起伏」「压力较大，建议寻求支持」

<InfoBox variant="warning" title="请阅读">

本结果仅供自我评估参考，不构成医学诊断；如有困扰请寻求专业帮助。
如需倾诉，「我的」页提供心理援助热线 **12356**（24 小时），可一键拨打。

</InfoBox>

历史结果在「明细 → 测评」查看。

### 账户、转账与余额调整

「我的」→「账户与转账」：

- **账户余额**：点「添加账户」，填名称与币种。**币种创建后不可改**
- **转账**：资金在自己账户间挪动，**不计入收支统计**；跨币种转账需填写转入实收金额
- **余额调整**：对账纠偏、补初始余额，金额可负，同样不计收支

### 借贷往来

对首页说「借出100」即可记录借出、收到借款或还款；「我的」→「借贷记录」查看往来与未结余额。

## 常见问题

**换手机或换了微信，历史数据还在吗？**
在。两种情况：

- **新手机、同一微信**：直接登录即可看到全部数据
- **换了新微信**：打开小程序（会登录为一个全新空账号）→ 点「去绑定」→ 输入原来绑定的手机号并获取验证码 → 提示「该手机号已绑定其他微信」时点「**继续接管**」。接管后原账号的全部数据在新微信上恢复；旧微信再登录只会看到全新空账号，**看不到你的任何数据**；网页版等其他设备需重新登录

安全边界：验证码发到谁的手机，谁才能接管——与网页版短信登录同一信任级别。

**识别错了怎么办？**
刚记完点卡片上的「改类目」；更早的记录说「删掉××」重新记。AI 会记住你的纠正，越用越准。

**记错了想删？**
刚记完点「撤销」；更早的对首页说「删掉××」，逐条确认后删除。

**小程序和网页版什么关系？**
同一账号数据互通。小程序随手记，[网页版](https://life.ccleeai.com)提供统计图表、聊天模式等完整功能（「我的」页可复制网址）。

**朋友怎么打开小程序？**
首页、明细、测评、资产页可转发好友或分享朋友圈；对方打开登录即可使用（朋友圈点开为只读预览）。
