# 网页版使用手册

本手册对应 **Life 网页版**（[life.ccleeai.com](https://life.ccleeai.com)）。网页版是功能最完整的端：
[小程序](/docs/life/miniprogram-guide)主打随手记与查看，聊天模式、统计图表、预算、模板补录、账号注销等完整能力都在这里。两端同一账号，数据实时互通。

## 快速开始

<StepBox title="1. 登录（首次登录即注册）">
打开 life.ccleeai.com，输入手机号 → 点「发送验证码」→ 输入短信验证码 → 点「登录」。
首次登录自动完成注册，无需单独的注册步骤。
</StepBox>

<StepBox title="2. 记下第一笔">
首页输入框写着「说点什么：花了20 / 这个月花了多少 / 删掉昨天的咖啡 / 把午餐改成40」——像发消息一样说一句，
结果卡立即给出识别结果。确认前不会写入；记错了可「撤销」，类目不对可「改类目」。
</StepBox>

<InfoBox variant="info" title="开放注册">

Life 当前开放注册：任意手机号验证短信即可登录使用，无需邀请。首次使用会有示例引导，
照着点就能学会——所有写入操作都有确认卡，放心说。

</InfoBox>

## 记录与查询（首页）

**能说什么**（首页空态的示例）：

| 想做什么 | 可以这样说 |
|---|---|
| 记支出 | 午餐花了 28 / 买咖啡 25 |
| 记情绪 | 今天有点累 / 心情不错，7 分 |
| 记待办 | 明天交报告 / 周五记得复诊 |
| 记服药 | 吃了感冒药 / 维生素 1 片 |
| 改 / 删 | 删掉昨天的咖啡 / 把午餐改成40 |
| 查询 | 这个月花了多少 |
| 设预算 | 餐饮预算 2000 |

**首页看板**：总资产、本月结余（含预算剩余）、今日支出、本月支出、最近记录（右上角带待办完成徽标，如「待办 3/5」）。

**所有写入都有确认卡**：

- **记好了**：「已记 N 笔」，可「撤销」或「改类目」
- **改 / 删**：列出候选，逐条「确认修改 / 确认删除」（删除不可恢复）
- **批量改**：先预览命中范围（如「7 月的打车」），确认后一次应用
- **没找到**：点「补充」写下你本来的意思，帮它重新定位
- **识别错了**：点「识别错了」告诉它本该是什么——AI 会记住，越用越准（详见[纠正示例](#纠正示例)）

## 聊天模式

首页输入区右侧的聊天入口进入（「纯聊天模式 · 可发图片记小票」）。

- **输入模式**：自动 / 心情 / 收支 / 待办 / 服药 / 聊天。默认「自动」——记账、查询、改错都行；
  切到「聊天」则只聊天和查询，不记数据
- **发图片**：小票、账单截图直接发，自动识别文字入账；也可以继续打字补充说明
- **陪伴角色**：「倾听者」或「客观中立」，随时切换
- **新对话**：清空当前会话重新开始；历史回看仍保留（「以上为历史」分隔线以下可回看）

<InfoBox variant="info" title="安全提醒">

聊天中出现相关信号时，页面会展示心理援助热线 **12356**（全国统一，24 小时）。
该提醒始终生效，不受任何设置影响。

</InfoBox>

## 统计与预算

首页快捷入口「数据统计」进入：

- **收支（近 6 月）**：支出 / 收入趋势
- **支出分类**：环形图，可切 本月 / 上月 / 近 3 月
- **预算对比**：按分类对比预算与实际支出——在统计页「批量设置 / 编辑预算」直接填，
  或在首页说「餐饮预算 2000」由 AI 设置
- **情绪趋势（近 30 天）**：平均分与低 / 中 / 高区分布
- **待办完成率**

## 收支管理（收支 tab）

底部第二个 tab「收支」进入收支记录页：

- **时间筛选**：本月（日历面板）/ 近3月 / 近6月 / 今年 / 全部
- **行内编辑**：点记录直接改分类、金额、币种、备注
- **分类管理**：新增自己的分类，可填「锚点词（可选，帮 AI 识别）」——比如建「宠物」分类、
  锚点词填「狗粮/猫粮」，以后说「狗粮 120」就自动归类
- 删除需逐条确认（「删除该收支记录？」）

## 账户、转账与借贷

首页快捷入口「账户转账」进入账户页：

- **添加账户**：名称 + 币种（**创建后不可改**）；可填锚点词（如「招行/储蓄卡」）帮 AI 识别
- **转账**：资金在自己账户间挪动，**不计入收支统计**；跨币种需填「收到金额」
- **余额调整**：利息 / 手续费 / 开户余额 / 对账修正等，金额可负数，不计收支；原因从固定选项里选
- 转账 / 调整流水可删除（删除后账户余额相应回退）
- **借贷**：对首页或聊天说「借出100」「还了 50」即可记录借款、还款，随时问「某某还欠多少」

## 情绪与压力自评

首页快捷入口「心理健康」进入：

1. 选择一份自评：**情绪自评 / 压力自评 / 情绪速测**（页面上显示「N 题 · 满分 M」）
2. 一屏一题，按「过去两周内」真实情况作答（完全不会 / 好几天 / 一半以上 / 几乎每天）
3. 提交后即时出结果（如「状态平稳」「压力较大，建议寻求支持」），可「再测一次」
4. 「历史记录」留存每次结果；「筛查趋势（近 14 天）」展示变化

**题目来自哪里，专业吗？**

三份自评的题目来自国际通行的标准化量表：**情绪自评**对应 PHQ-9、**压力自评**对应 GAD-7、
**情绪速测**（PHQ-4）是两者的简短组合。它们被广泛用于情绪与压力状况的初步自我评估；
计分与结果分级由服务端统一计算。

<InfoBox variant="warning" title="请阅读">

本结果仅供自我评估参考，不构成医学诊断；如有困扰请寻求专业帮助。
如果你正在经历痛苦，或有伤害自己的念头：你不必独自承受——心理援助热线 **12356**（全国统一，24 小时）；
情况紧急请前往就近医院急诊或精神卫生中心。

</InfoBox>

## 模板与批量补录

首页快捷入口「模板补录」进入，适合**漏记的固定事项**（房租、每日服药、工资）：

1. **新增模板**：选类型（收支 / 情绪 / 待办 / 服药），填好固定内容（如「房租 3000」「二甲双胍 1 片」）
2. **批量补录**：选模板 → 设「每天条数 / 天数 / 截止日期」→ 预览补录范围（如「7月1日 ～ 7月31日 · 每天 1 条 · 共 31 条」）→ 确认
3. 只补**过去**日期，不会生成未来记录；**系统不会自动查重**，重复提交会产生重复记录（确认弹窗会明示）

## 纠正示例

设置页或首页快捷入口进入。你在结果卡上的每次纠正（改类目、识别错了）都会自动沉淀为「教学示例」，
AI 之后会按你的说法理解。这个页面可以查看已积累的示例（如「宠物零食 → 宠物」），删掉不再想教的。

## 设置与账号

右上角齿轮进入设置页：

- **主题**：跟随系统 / 浅色 / 深色
- **主动关心**：聊天里主动关心你的频率（常规 / 适度 / 关闭）；出现安全信号时始终提醒
- **记账结余提示**：记支出后在确认消息里追加本月结余与预算剩余（显示 / 隐藏）
- **默认币种**：记账未提到币种时按此落库（不做汇率换算）
- **昵称**、**退出登录**

<InfoBox variant="warning" title="注销账号">

设置页底部「危险操作」→「注销账号」：短信验证后**永久删除全部数据**（收支、情绪、服药、借贷、账户等），无法恢复。
只是想删几条记录的话，用各页的逐条删除即可，不要注销。

</InfoBox>

## 常见问题

**网页版和小程序什么关系？**
同一账号、同一份数据，实时互通。小程序适合随手记，网页版功能最全（聊天模式、统计、预算、模板补录、注销）。
建议：平时小程序随手记，复盘时上网页版看统计。

**换手机 / 换设备怎么办？**
数据在服务器，任何设备浏览器打开 life.ccleeai.com，手机号 + 验证码登录即可，历史数据全在。

**AI 理解错了怎么办？**
四层修正，越用越准：结果卡「撤销 / 改类目」救回这一条；「识别错了」教它下次别错；
「补充」帮它定位没找到的记录；长期习惯可用「纠正示例」页管理。

**我的数据安全吗？能彻底删除吗？**
敏感内容加密后存储，系统日志不记录原文（详见[隐私与数据安全](/docs/life/privacy-security)）。
单条记录逐条删除；要彻底清除则用「注销账号」，永久删除、无法恢复。

**情绪自测是医疗诊断吗？**
不是。自评结果仅供自我了解参考，不构成医学诊断；如有困扰请寻求专业帮助（页面常驻热线 12356）。

**支持哪些币种？会自动换汇吗？**
支持人民币 / 美元 / 欧元 / 日元 / 港元 / 新台币，按原话币种记录，统计按币种分组，**不做汇率换算**。
