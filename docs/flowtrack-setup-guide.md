# 开物智造初始设置教程

开工前把三件事配好，后面建工单、跟进度就顺了：**添加工序 → 组工艺路线 → 成员分角色**。全部在手机企微里完成，约 10 分钟。

## 开物智造支持哪些渠道？

| 渠道 | 支持情况 |
|------|---------|
| 企业微信 | 已支持（深度集成：通讯录、扫码、部门同步） |
| 浏览器 / PC | 已支持 |
| 钉钉、飞书 | 支持接入 |
| 微信服务号 | 支持接入（面向外协厂、客户查进度、收预警） |
| 微信小程序 | 支持接入（定制） |
| 短信、邮件 | 支持（关键预警兜底） |

本篇教程按企业微信内的使用路径截图演示。

## 快速开始

1. 打开企微里的开物智造，进入「我 → 设置」
2. 「工序」里把厂里每道加工步骤加进去（比如下料、机加、焊接、组装、检验，示例共 5 道）
3. 「工艺路线」新建一条路线，把工序按顺序串起来、填上每道天数
4. 「成员与权限」里给每位同事分好角色
5. 回到首页新建第一张工单，选产品、选路线，开工

下面每一步都有截图对照。

## 使用指南

### 任务一：怎么添加工序

1. 进入「我 → 设置」，这里集中了编号规则、术语、工序、工艺路线、成员与权限等配置，开工前只需要动「工序」「工艺路线」「成员与权限」三项。

<img src="/images/docs/flowtrack/01-settings-home.webp" width="480" loading="lazy" />

2. 点「工序」。第一次进来是空的，点「＋ 加工序」开始添加。

<img src="/images/docs/flowtrack/02-processes-empty.webp" width="480" loading="lazy" />

3. 输入工序名（按厂里的习惯叫法，比如「机加」），点确定。

<img src="/images/docs/flowtrack/03-process-add-filled.webp" width="480" loading="lazy" />

4. 一道道加完。顺序不影响使用，排产时按路线里的顺序走。示例厂加了下料、机加、焊接、组装、检验共 5 道。

<img src="/images/docs/flowtrack/04-processes-list.webp" width="480" loading="lazy" />

### 任务二：怎么组一条工艺路线

工艺路线就是某类产品从开工到完工的固定走法：依次经过哪些工序、每道做几天。建一次，以后每张工单直接选用。

1. 「设置 → 工艺路线 → 新建」，进入画布。

<img src="/images/docs/flowtrack/05-routes-empty.webp" width="480" loading="lazy" />

2. 点「添加第一道工序」。

<img src="/images/docs/flowtrack/06-route-canvas-empty.webp" width="480" loading="lazy" />

3. 从工序库里选开头那道，比如「下料」。

<img src="/images/docs/flowtrack/07-route-pick-process.webp" width="480" loading="lazy" />

4. 选中节点后点「＋」追加下一道，逐道串完；每选中一道，在下方面板里填工期（天）。示例路线 5 道共 7 天，系统自动合计。

<img src="/images/docs/flowtrack/08-route-canvas-built.webp" width="480" loading="lazy" />

5. 左上角给路线起个名（比如「标准加工路线」），点保存。

<img src="/images/docs/flowtrack/09-routes-list.webp" width="480" loading="lazy" />

### 任务三：怎么给成员分角色

同事从企微进来就能看到「成员与权限」，但没分角色前处于「待分配」状态——**看不到任何数据**，需要管理员分配后才能正常使用。

1. 「设置 → 成员与权限」总览：谁能干什么，一张表看清。

<img src="/images/docs/flowtrack/10-members-overview.webp" width="480" loading="lazy" />

2. 点「待分配」筛出还没角色的人。

<img src="/images/docs/flowtrack/11-members-pending.webp" width="480" loading="lazy" />

3. 在人名右侧的下拉里选角色：跟单员管建单跟单，生产人员干活报进度。选完立即生效，不用对方重新登录。

<img src="/images/docs/flowtrack/12-members-assigned.webp" width="480" loading="lazy" />

## 下一步：建第一张工单

设置完成。回首页「＋ 新建工单」，选产品后路线就能直接选，选中路线工期自动带出，照着跟进度即可。

<img src="/images/docs/flowtrack/13-new-order-ready.webp" width="480" loading="lazy" />

## 注意事项

- 被工艺路线引用的工序**不能删，只能停用**；停用后历史工单不受影响，只是新建时选不到了。零引用的工序可以直接删。
- 改工序名前，系统会提示这个名字被多少条路线引用，改完路线同步跟着变。
- 编号规则（按年/按年月、带不带分隔符）决定新建工单的工单号流水；改设置只影响之后的新单，老单号不变。
- 已完工、已取消的工单整单只读，谁都不能再改。

## 常见问题

### 工序管理是什么意思？

把一件产品的加工过程拆成一道道能单独跟进度的小步骤，比如下料、机加、焊接、组装、检验（示例 5 道）。在开物智造里，你在「设置 → 工序」把厂里实际有的工序加进去，排产、报进度都以这份清单为准。结论：工序清单是整个系统跟进度的基础，先加它。

### 工艺路线是什么意思？

一件产品从开工到完工依次经过哪些工序、每道做几天的固定走法。比如标准加工路线：下料 1 天 → 机加 2 天 → 焊接 1 天 → 组装 2 天 → 检验 1 天，共 7 天。结论：同类产品建一条路线反复用，建工单时直接选，不用每次重排。

### 工艺路线怎么设置？

三步：「设置 → 工艺路线 → 新建」进画布；按加工顺序逐道加工序、每道填工期天数；起名保存。每道工期相加就是路线总工期（示例 5 道共 7 天，自动合计）。详细截图见上文「任务二」。

### 新成员登录后看不到数据怎么办？

新成员未分角色前处于「待分配」状态，看不到任何数据——这是刻意的权限保护。管理员进「设置 → 成员与权限」，点「待分配」，在名字右侧下拉选「跟单员」或「生产人员」，保存后立即生效，无需重新登录。结论：分配角色即解决。

### 工序加错了能删吗？

分两种情况：还没被任何路线引用的工序，可以直接删；已被路线引用的删不掉，只能停用（停用后历史工单照旧，新建时不再出现）。动手时系统会明确告诉你「被 N 处引用，请改为停用」。结论：能删的直接删，被引用的停用即可，数据不会乱。
