# 开物智造是什么

## 开物智造是什么

开物智造是一款装在企业微信里的生产进度管理工具，面向按订单生产的中小工厂。它回答三个每天都会被问到的问题：这张工单做到哪道工序了、还剩几天、会不会晚——预警提前给出来，管理员当场改计划，不用追着人问。

名字取自《天工开物》——明末宋应星写成的中国制造业原典，记录了几十个行业的手艺与工序。「开物」二字暗含工艺、工序，正对应《智能制造典型场景参考指引（2025年版）》里工艺数字化设计、生产排程这类典型场景；「智造」说的是落地方式：不用装 App，在员工已经在用的办公平台里打开就能用。

## 开物智造解决什么问题

按订单生产的厂，进度账大多散在三处：Excel 表里排产、微信群里问「做到哪了」、车间里靠纸质流转卡传。单子一多，麻烦就集中在三件事上：每张单现在哪道工序、还剩几天、会不会晚——等发现晚了，能补的时间已经不多。

开物智造把这三件事变成首页上看得见、能处理的事：

- 工单卡按「要不要你动作」分区：交期预警 / 今天交期 / 暂不处理 / 正常，先处理要紧的
- 预警卡点「去处理」进决策页：晚的原因、改天数试算、改交期、暂不处理，一条路走完
- 每张单当前工序实时可查，生产人员两步报工，不用在群里追问

## 开物智造适合谁用

按订单生产、靠按时交货的中小工厂，非标、标品都适用，工单要走多道工序的厂最合适。厂内四类角色（管理员、跟单员、生产人员、自定义角色）按 7 个权限点分工；新同事进来看不到数据是刻意的权限保护，管理员分好角色才能正常使用。

边界也说清楚：开物智造不做库存、成本、工资、审批，也不按件数追进度。要回答的是「这单会不会晚」，它合适；要管仓库和工资，它不是工具。

## 开物智造支持哪些平台

业务界面一套，平台差异只在能力层：

| 渠道 | 支持情况 |
|------|---------|
| 企业微信 | 已支持（深度集成：通讯录、扫码、部门同步） |
| 浏览器 / PC | 已支持 |
| 钉钉、飞书 | 支持接入 |
| 微信服务号 | 支持接入（面向外协厂、客户查进度、收预警） |
| 微信小程序 | 支持接入（定制） |
| 短信、邮件 | 支持（关键预警兜底） |
