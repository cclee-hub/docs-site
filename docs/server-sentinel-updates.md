CCLee 服务器哨兵保持活跃更新。本页按时间倒序记录每个版本的新增功能与能力改进，当前最新版本为 **2.2.0**。产品能力总览见 [CCLee 服务器哨兵](/docs/server-sentinel)。

## 版本升级与版本号查看

版本升级统一下发，全链路托管与自助授权都无需你操作。每封告警通知的页脚都带有当前版本号（monitor-cli vX.X.X），可直接查看。

## 2.2.0：事件通知直接点名变了什么（2026-10-02，当前版本）

### 新增

- **关键项变化的通知附具体清单**：定时任务、系统服务、系统账号有新增、移除或改动时，通知逐条列出是哪一条变了（最多列 10 条并给出总数）。是不是自己人做的变动，看完通知就有判断，不用再登服务器逐项核对

## 备份增强：服务器本地也留一份（2026-09-27）

### 新增

- **数据库备份在本地多留一份**：备份照常上传云端的同时，服务器本地额外保留最近 24 小时的副本。某晚云端上传出状况，当天的备份在本地照样拿得到
- **本地副本按日期命名**：今天的副本不会覆盖昨天的，需要时可逐日回取
- 加上正在使用的数据，同一份数据共有三份、分布在两个位置

## 2.1.1：证书到期监控覆盖各种存放形式（2026-09-26）

### 新增

- **按证书内容识别**：不看文件后缀名，cPanel 的合并证书、Let's Encrypt 的证书文件都能自动发现，纳入到期监控。服务器上有多少张证书就盯多少张，到期前会提前提醒
- **重复存放只提醒一次**：同一张证书在服务器上多处重复出现时，按一张证书计数，不会重复打扰
- **扫描范围可按主机定制**：证书放在非标准位置的服务器也能纳入扫描

## 2.1.0：陌生 IP 识别自动学习，动态 IP 也适用（2026-09-18）

### 新增

- **陌生 IP 登录识别升级为自动学习**：自动记住这台服务器常用的登录来源，随时间更新（超过 90 天没再出现的来源自动淡出）。IP 经常变化的环境下也能分清熟客和真正的陌生来源，不用再手工维护 IP 白名单
- **陌生 IP 告警分级更细**：单独的陌生来源登录按「需处理·安全」档提醒；同一时段还出现大量登录失败（正在被试密码）时，直接升为紧急档
- **站点响应缓慢监控**：网站或接口响应持续偏慢时单独提醒；周检报告新增各站点平均响应段，可回看各站点的响应快慢

## 2.0.0：告警归并成事件，给结论不是甩数据（2026-09-17）

### 新增

- **事件结论**：同一时段的多来源信号自动归并成一条事件，按紧要程度分档（紧急 / 需处理 / 仅记录），每条附处置指引：问题是什么、紧不紧急、下一步做什么。相关信号全部恢复正常才发恢复通知
- **安全与入侵迹象监控扩面**：跑挖矿程序、改动网站核心文件、添加陌生账号、添加定时任务，这些入侵后的常见动作都在持续盯守之列；SSH 登录失败、陌生 IP 成功登录、防火墙封禁、应用关键报错一并纳入。入侵发现得越早越好处理，这些信号趁症状还没出现就能发现异常
- **报告内容更全**：周检报告新增「仅记录」事项段，月度报告新增「本月事件」段、可用性汇总与检查台账。不重要的事件不再逐条发邮件，按周按月汇总在报告里
- **公网探针正常时保持安静**：外部探针的例行验证只在异常时通知，一切正常不打扰

## 1.0.0：服务上线（2026-09-13）

首版交付：

- **四类监控**：性能（CPU、内存、磁盘、负载，每 5 分钟一轮采集）、可用性（本机自查 + 公网独立探针双向验证，机器活着且服务真的在响应才算数）、安全（防火墙状态、暴力破解尝试、登录记录、证书到期、安全更新持续在检）、备份（每日备份状态与云端核对，每月一次真实恢复演练，用实测证明备份能恢复）
- **报告体系**：异常即时通知、每周周检报告、每月月度报告
- **新服务器头 48 小时只观察不出警**：先摸清这台机器的正常脾气，再开始正式告警
- **监控系统自身也在被盯守**：两套独立机制互相盯着监控体系，不会出现「监控挂了都没人知道」
