# CCLee 服务器哨兵

一台服务器一份监控方案：要么我们替你盯到底，要么把现成的监控体系交到你手上。

## CCLee 服务器哨兵是什么

CCLee 服务器哨兵是面向 Linux 服务器的监控预警服务，覆盖性能、可用性、安全（含入侵迹象发现）、备份四类监控。按台开通：一台服务器对应一套验证，验证什么由这台机器上跑的服务决定。

两种用法任选：**全链路托管**——你零动作，出了问题我们处理并告诉你结果；**自助授权**——预警直达，你自行处置。

## 云厂商监控、面板工具之外，你还缺什么

服务器上跑着网站、接口和后台应用，现有工具其实不少：云厂商监控给你 CPU、内存、磁盘曲线；主机面板工具给你服务状态和安全日志；Uptime 类工具盯着首页能不能打开。但它们大多停在「给你数据」，有几件事没人替你做：

- **内部坏掉，页面看不出来**。页面打得开、进程还在跑，但后台连不上数据库、支付一直在失败——这种关键报错首页探活发现不了，往往要等到客户投诉、财务对账对不上才暴露。
- **安全日志一堆，轻重没人分**。一天几百条爆破尝试，绝大多数是常规扫描，但里面可能混着一次陌生 IP 的成功登录。工具会记录，不替你判断哪条危险。
- **入侵没有症状**。被挖矿、网站文件被篡改、被偷偷加了定时任务或陌生账号，往往等到机器变卡、页面异常才被发现，而付费安全防护并不便宜。
- **备份存在不等于备份可用**。备份文件一直在生成，等真出事要恢复时才发现打不开、恢复不出来——很多人从没验证过，数据丢了才暴露。
- **监控系统自己也可能挂**。监控挂了、告警静默了，谁盯着监控系统？

CCLee 服务器哨兵补的就是这几块：把「这台机器跑得好不好、哪些问题要紧、备份到底能不能恢复」验证清楚，出了问题，处理过程和结果都说得清楚。

## 两种服务形态：先对表，再细看

| | 全链路托管 | 自助授权 |
|---|---|---|
| 你要做什么 | 签约后零动作 | 开通后自己处置告警 |
| 谁来处理问题 | 我们处理，处理完告诉你结果 | 你自行处置 |
| 你收到什么 | 问题结论与处理结果 | 事件告警与周检、月度报告 |
| 适合谁 | 不想碰服务器、没有技术团队的你 | 有点技术、不想从零搭监控的你 |

两种形态共用同一套监控引擎，按台开通，不是两套割裂的产品；同一台服务器可以先自助、后转托管。下面分别展开。

## 全链路托管：你不用管，我们来

**你要做的**：签约、完成一次接入授权。之后零动作——监控接入、日常盯守、问题处置都不需要你参与。

**我们做的**：监控 7×24 小时持续运行（每 5 分钟一轮采集，公网探针独立验证）。发现异常先核实再定级，需要处理的问题由我们处置，处理到恢复为止，然后把发生了什么、怎么处理的、现在什么状态告诉你。你收到的不是一堆报警邮件，是结论。

**出了问题算谁的**：托管线路里责任在我们——不存在「工具报了警、但没人负责处理」的中间地带。响应按紧急程度分级：紧急问题立即启动处置，时限在签约时的服务约定里逐档写明，白纸黑字，不靠口头。

**凭什么放心**：

- 持续异常才通知，偶发抖动不打扰你；
- 新接入的服务器头 48 小时只观察不出警，先摸清这台机器的正常脾气，再开始正式告警；
- 监控系统自身也被两套独立机制互相盯着，不会出现「监控挂了都没人知道」；
- 备份每月真实恢复一次给你看，不是只确认备份文件存在。

## 自助授权：现成的监控体系直接用

不想从零搭监控、又愿意自己处置告警，选自助授权：监控项、告警、报表体系都是现成的，开通后预警直达你。你的服务器会被监控什么，逐类说清：

### 性能：资源水位持续可见

CPU、内存、磁盘、负载每 5 分钟采集一轮，指标连续多轮超阈值才触发告警，偶发的瞬时尖峰不会打扰你。

### 可用性：本机和公网两个方向都验证

机器活着不等于服务可用。本机自探确认服务进程在响应，独立外部探针再从公网视角验证一遍（适用于有公网入口的服务），两个方向都通过才算可用。

### 安全：从日志噪音里挑出真信号

防火墙状态、爆破尝试、登录记录、证书到期、安全更新持续在检。陌生 IP 成功登录、拦截量陡增这类信号单独判级，把真正需要关注的挑出来，而不是把日志原样丢给你。应用关键报错也按错误窗口计数（一段时间内关键报错出现了多少次）持续在检。

### 入侵迹象：趁症状还没出现先发现

挖矿进程、定时任务与启动项的基线（这台机器正常状态的样子）变动、基线之外的新增账号——按基线比对发现异常，并附处置建议。

### 备份：不只盯「有没有备份」，还验证「能不能恢复」

每日备份状态核对，备份文件与对象存储桶（备份文件在云端的存放处）交叉核对；每月一次真实恢复演练，把数据库恢复出来逐表计数核对，用实测数字证明备份可用。

**环境自动适配**：产品的差异化在「通用监控引擎 + 按需适配」。一套引擎覆盖各类 Linux 服务器，常见的运行环境会被自动识别，直接加载对应的专属监控项，不用你告诉我们该看什么；未适配的环境由通用监控项兜底，特殊业务按需定制扩展。

## 告警长什么样：给结论，不是甩数据

一晚上几十封原始报警，是要你自己找关联的。CCLee 服务器哨兵把同一时段的多来源信号（可用性、关键报错、安全、备份）归并成一条事件，结合这台服务器承载的业务判定紧要程度，附上处置指引——问题是什么、紧不紧急、下一步做什么。需要行动的事项即时通知，只需知晓的内容归入周检报告。

对没有专职运维的团队，这让告警从「看不懂、要么信息过载要么直接忽略」变成「看得懂、知道下一步怎么办」。
